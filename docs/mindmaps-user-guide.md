# Manuel d'utilisation des cartes mentales

Les cartes mentales permettent d'organiser visuellement les idees d'un projet : personnages, lieux, intrigues, relations, themes, pistes de recherche ou structure narrative.

## Acceder aux cartes mentales

1. Ouvrez un projet.
2. Dans la barre laterale, cliquez sur **Cartes mentales**.
3. La page affiche un bouton de creation et la liste des cartes deja creees.

## Creer une carte mentale

1. Cliquez sur **Creer une nouvelle carte mentale**.
2. Une carte vide s'ouvre avec un premier sujet central.
3. Renommez le sujet central avec l'idee principale de la carte.

Exemples :

- "Relations entre personnages"
- "Intrigue principale"
- "Univers politique"
- "Systeme de magie"
- "Plan du tome 1"

## Ajouter et organiser des idees

Dans l'editeur, utilisez la barre d'outils, le menu contextuel ou les raccourcis clavier proposes par l'outil pour :

- ajouter une idee enfant ;
- ajouter une idee au meme niveau ;
- renommer une idee ;
- supprimer une idee ;
- deplacer une idee dans la carte ;
- reorganiser les branches par glisser-deposer.

Conseil : partez d'une idee centrale simple, puis ajoutez progressivement des branches. Une carte mentale reste plus lisible quand chaque noeud contient une idee courte.

## Exemple de structure utile

Pour une carte de personnages :

- Personnages
- Protagoniste
- Objectif
- Peur
- Relation avec l'antagoniste
- Antagoniste
- Motivation
- Faiblesse
- Allies
- Liens avec le protagoniste

Pour une carte d'intrigue :

- Intrigue principale
- Incident declencheur
- Obstacles
- Rebondissements
- Climax
- Resolution

## Sauvegarder une carte

Quand la carte est prete :

1. Cliquez sur **Creer la carte mentale** lors de la creation.
2. Cliquez sur **Modifier la carte mentale** lors de l'edition.

Le titre de la carte est repris depuis le sujet central. Pensez donc a donner un nom clair au noeud principal avant de sauvegarder.

## Modifier une carte existante

1. Depuis la page **Cartes mentales**, trouvez la carte dans la liste.
2. Cliquez sur l'icone de modification.
3. Modifiez les branches ou le titre central.
4. Cliquez sur **Modifier la carte mentale** pour enregistrer.

## Visualiser une carte

Depuis la liste des cartes mentales, cliquez sur **Ouvrir** pour consulter une carte en lecture seule.

Dans ce mode :

- la carte ne peut pas etre modifiee ;
- le menu contextuel et la barre d'outils ne sont pas actifs ;
- vous pouvez exporter la carte en image.

## Exporter une carte en image

1. Ouvrez la carte en mode visualisation.
2. Cliquez sur le bouton de telechargement.
3. La carte est exportee au format PNG.

Cet export est pratique pour l'inserer dans un document, la partager ou garder une capture de travail.

## Utilisation hors ligne

Les cartes mentales peuvent etre creees ou modifiees hors ligne. Dans ce cas :

- les changements sont sauvegardes localement ;
- ils seront synchronises avec l'API quand la connexion sera retablie ;
- la carte reste disponible dans le projet pendant le mode hors ligne.

## Bonnes pratiques

- Donnez un titre court et explicite au sujet central.
- Limitez chaque noeud a une seule idee.
- Utilisez les branches pour regrouper les informations par theme.
- Creez plusieurs petites cartes plutot qu'une seule carte trop chargee.
- Exportez en PNG les cartes importantes avant une presentation ou une sauvegarde externe.

## Quand utiliser une carte mentale ?

Utilisez une carte mentale quand vous voulez :

- explorer une idee encore floue ;
- visualiser les relations entre personnages ;
- clarifier une intrigue complexe ;
- organiser un univers ;
- preparer un plan de chapitre ou de partie ;
- garder une vue d'ensemble sans ecrire un long document.
